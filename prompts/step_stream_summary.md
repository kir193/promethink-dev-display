# Краткое описание step stream

Используйте этот prompt, когда нужно превратить поток событий в короткий
readable summary для UI.

## Типы событий

- `session`
- `turn_start`
- `step_start`
- `action`
- `action_result`
- `step_end`
- `persisted`
- `done`
- `error`

## Правила вывода

- показывайте только короткие summaries;
- не выводите сырой reasoning dump;
- не добавляйте лишнюю техническую воду;
- если событие неполное, честно об этом сообщайте;
- если есть ошибка, показывайте её коротко и понятно.
