# Visual Display Brief

Этот brief нужен, чтобы подготовить данные для экрана Promethink.

## UI sections

- mission brief
- sprint protocol
- status panel
- live stream summary
- source label
- empty state

## Rules

1. Не менять shell layout.
2. Не добавлять новые панели.
3. Показывать project sprint list только из explicit source.
4. Если source отсутствует, показывать empty state.
5. Если приходит step stream, показывать только readable summaries.
